# tutor-tic-psicolog-a
Tutor de estudio con IA para Tecnologías de la Información y la Comunicación, Psicología Clínica 1.er nivel (UTA). Contenidos de las 4 unidades, talleres PAE 1 a 4, autoevaluación y fichas sobre comunicación, ética digital, búsqueda científica, Excel y divulgación en salud mental. La IA funciona con la clave gratuita de Gemini de cada estudiante.
